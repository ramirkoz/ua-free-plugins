# KOZ Consent Manager 0.2.9
> Multilingual consent-banner templates with per-language storage and English fallback.

Privacy-first visitor consent and a local allowlist for optional WordPress scripts.

## Ownership and project history

Developed, owned and maintained by **Tony Kozyriev** (`ramirkz`). Originally built for the **UA FREE charitable foundation**, whose website remains the first production and testing environment. UA FREE does not own the plugin or its source code.


## Multilingual banner templates

The settings screen edits the banner template for the current WordPress user language. The frontend selects the template from the current page locale. Ukrainian, English, Chinese, Spanish, Arabic, Indonesian, Portuguese, French, Japanese, German and Hindi are included; unsupported locales use English. Existing single-language text is preserved under the site language during migration.

## Compatibility

The public plugin slug is `koz-consent-manager`. Legacy internal option names and data structures are retained where required for migration compatibility.
