# KOZ Suite Bundle 1.0.2

Current synchronized release library for the 12 public KOZ WordPress plugins.

Four plugins have completed the stricter WordPress.org re-audit: Copy Actions 1.1.11, URL-Only Comment Spam 1.1.9, Consent Manager 0.2.10 and Donate Stats & Conversions 1.3.9.

The remaining eight packages are preserved as the previous live baseline and are explicitly not marked current WordPress.org-ready until their re-audit is complete.

Canonical bundle and plugin ZIP files are stored in the synchronized Google Drive release folder referenced in the manifest.
