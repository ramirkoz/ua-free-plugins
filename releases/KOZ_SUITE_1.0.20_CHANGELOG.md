# KOZ Suite 1.0.20 — Changelog

Release date: 2026-08-17

## Changed components

- **KOZ 404 Guard & URL Intelligence 2.1.3** — blocks WordPress guessed redirects for obsolete language-like deep 404 routes so legacy PL/IT/CS/RO paths remain real 404s instead of collapsing to Ukrainian pages; explicit redirects and active translation routes are preserved.
- **KOZ Copy Actions 1.1.13** — aligns runtime admin/frontend notices with the Suite language standard: UK + EN/ZH/ES/AR/ID/PT/FR/JA/DE/HI. Copy-action functionality is unchanged.

Both changed plugins passed production functional validation and WordPress Plugin Check on WordPress 7.0.4.

WordPress.org currently remains live on Copy Actions 1.1.12; 1.1.13 is the canonical package for the next SVN publication.

All other 10 public plugin packages are unchanged from Suite 1.0.19. Private Hub 0.4.5 remains excluded.
