# UA FREE WordPress Plugin Suite 3.0

**Twelve independently installable, privacy-first WordPress plugins built from real operational work for the UA FREE charitable foundation.**

Use one plugin, several plugins, or the complete suite. Every package in this release passed a live WordPress Plugin Check on the foundation website.

> **Most users should download one individual plugin ZIP from the Assets section below.** The full release library is intended for maintainers and bulk distribution. It is not a WordPress plugin and must not be uploaded directly through the WordPress plugin installer.

## Why this suite is useful

- Practical tools for migration, translation, SEO, consent, donations, Google Ads, accessibility and spam control.
- Each plugin works independently. There is no required framework or paid core plugin.
- No Suite-wide telemetry, fingerprinting or hidden usage reporting.
- No custom updater that bypasses WordPress.org.
- Administrative actions use WordPress capabilities, nonces and sanitization.
- Responsive **UA FREE Support Panel v2.1** is included across the suite.
- Live WordPress Plugin Check: **12/12 PASS**.

## Quick installation

1. Open the **Assets** section at the bottom of this release.
2. Download the ZIP for the plugin you need.
3. In WordPress, go to **Plugins → Add New Plugin → Upload Plugin**.
4. Select the downloaded ZIP, choose **Install Now**, then **Activate**.
5. Open the plugin settings page and review its options before enabling production features.

To update an installed UA FREE plugin manually, upload the newer ZIP through the same WordPress screen and choose **Replace current with uploaded** when WordPress offers the replacement.

## Verify downloaded files

The release includes:

- `SHA256SUMS.txt` with checksums for every individual plugin ZIP and the full library.
- A separate `.sha256` file for each downloadable ZIP.
- `manifest.json` with plugin versions, sizes and SHA-256 values.

Linux or macOS:

```bash
sha256sum -c SHA256SUMS.txt
```

Windows PowerShell:

```powershell
Get-FileHash .\ua-free-copy-1.0.7.zip -Algorithm SHA256
```

Compare the result with the matching value in `SHA256SUMS.txt`.
