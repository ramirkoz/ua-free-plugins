# KOZ Suite 1.0.0 — Changelog

Release date: 2026-08-04

## Suite release

- Completed rebranding of the 12-plugin public suite from UA FREE naming to KOZ.
- Added a unified KOZ Suite menu and Control Center.
- Added locale-aware administration interfaces for 10 site languages plus English fallback.
- Preserved migration compatibility for existing UA FREE settings, options, routes and integrations where required.
- Separated independent developer ownership/support from charitable support for the UA FREE foundation.
- Removed bundled PO/MO translation files from WordPress.org packages.
- All 12 production packages passed live functionality checks and WordPress Plugin Check.
