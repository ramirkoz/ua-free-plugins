# KOZ WordPress Plugin Suite 1.0.30

Release date: 2026-09-25

- Public bundle: 12 independently installable plugins.
- KOZ Site Bridge updated to 0.5.7.
- Site Bridge 0.5.7 passed Plugin Check on the foundation site and was uploaded to the existing WordPress.org review submission.
- Site Bridge no longer auto-deactivates the legacy UA FREE package.
- X-KOZ-Key is explicitly documented as local REST authentication, not licensing or feature gating.
- The public /openapi endpoint exposes schema only; diagnostic endpoints remain authenticated.
- Other 11 public plugins remain unchanged from Suite 1.0.29.
