# KOZ Translate Diagnostics

Version 0.3.4. Read-only diagnostics and privacy-safe JSON reports for KOZ Static Translate.

Originally developed for the UA FREE charitable foundation website. Independently owned and maintained by Tony Kozyriev.


## 0.3.4

Fixes translation readiness so it follows the same effective rendering fallback as KOZ Static Translate: current ready translation first, translation memory second. Queue state does not determine page readiness. Global deep totals now report effective ready segments and memory-fallback segments. The plugin remains read-only and does not alter robots directives.

## 0.3.3

Adds deep page-level translation readiness, critical metadata/H1 checks and mixed-language blocker detection. The plugin remains read-only and does not alter robots directives.
