# UA FREE Donate Stats & Conversions 1.2.10

## Мовні версії

Якщо активний UA FREE Static Translate, плагін автоматично додає всі активні мовні маршрути для вибраної сторінки WordPress. Після збереження вони відображаються під основною сторінкою та не потребують ручного введення.

## Для менеджера

Плагін показує:

- відвідування сторінки донатів;
- натискання «Підтримати»;
- відкриття оплати;
- копіювання реквізитів;
- підтверджені донати;
- конверсію.

## Підтверджений донат

Надійний режим використовує підписаний callback.

Платіжний сервіс або connector надсилає:

```json
{"event":"donation_success","reference":"unique-provider-reference","provider":"payment","language":"uk"}
```

Заголовок `X-UAFree-Signature` містить HMAC-SHA256 сирого JSON із секретом плагіна.

Плагін:

- не зберігає суму;
- не зберігає ім’я або email;
- не зберігає платіжні реквізити;
- не зберігає raw transaction/reference;
- зберігає лише HMAC-хеш reference, щоб не зарахувати callback двічі.

## Конверсія

`підтверджені донати / унікальні денні сесії × 100`.
