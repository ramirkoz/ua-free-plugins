# UA FREE Copy 1.0.3

- Налаштування відкриваються тільки через `UA FREE → Copy`.
- Старий пункт `Налаштування → UA FREE Copy` примусово прибирається.
- Вбудований дубльований список Suite видалено.
- Налаштування `uafree_copy_settings` і старі селектори зберігаються.
- Плагін не зберігає скопійовані значення і не робить зовнішніх запитів.
