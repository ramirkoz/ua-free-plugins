# UA FREE Suite Control Center 0.3.10

Центр стану та навігації UA FREE Suite.

Плагін не надсилає статистику встановлень, видалень або використання і не
виконує зовнішніх telemetry-запитів. Після оновлення він лише одноразово
видаляє локальні параметри та розклад, які могли залишитися від відхилених
тестових кандидатів.

Технічна папка та text domain залишаються
`ua-free-analytics-dashboard` для безпечної заміни попередньої версії.
