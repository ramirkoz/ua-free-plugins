# KOZ Google Ads Campaign Builder 1.4.7

Builds reviewable Google Ad Grants and standard Google Ads Editor import packages.

## Ownership and project history

Developed, owned and maintained by **Tony Kozyriev** (`ramirkz`). Originally built for the **UA FREE charitable foundation**, whose website remains the first production and testing environment. UA FREE does not own the plugin or its source code.

## Compatibility

The public plugin slug is `koz-google-ads-campaign-builder`. Legacy internal option names and data structures are retained where required for migration compatibility.
