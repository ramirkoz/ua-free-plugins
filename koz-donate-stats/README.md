# KOZ Donate Stats & Conversions 1.3.11
Local donation-journey analytics and consent-aware conversion events for WordPress.

## Ownership and project history

Developed, owned and maintained by **Tony Kozyriev** (`ramirkz`). Originally built for the **UA FREE charitable foundation**, whose website remains the first production and testing environment. UA FREE does not own the plugin or its source code.

## Compatibility

The public plugin slug is `koz-donate-stats`. Legacy internal option names and data structures are retained where required for migration compatibility.
